## 4. Evidence & Evaluation Rules

### Understanding of cloud platforms (AWS / Azure / GCP)
> **[AI Guidance — Evaluator Aid]**
> - **Concept Summary:** Cloud platforms provide scalable infrastructure for AI workloads via managed services like compute, storage, and databases.
> - **Strong Candidate Signals:** Deployed production ML models on AWS SageMaker or Azure ML; Managed cloud cost optimization for AI pipelines
> - **Weak / Ambiguous Signals:** Mentioned cloud without specific services or metrics; Tutorial-level cloud projects with no production impact
> - **Screening Question:** Have you deployed an AI model on AWS, Azure, or GCP in production?

### Knowledge of deployment, Docker, and basic DevOps practices
> **[AI Guidance — Evaluator Aid]**
> - **Concept Summary:** Docker containers package applications with dependencies for consistent deployment across environments.
> - **Strong Candidate Signals:** Containerized AI models using Docker and CI/CD pipelines; Implemented infrastructure as code for model deployments
> - **Weak / Ambiguous Signals:** Basic Docker knowledge without production deployments; Manual deployment processes without automation
> - **Screening Question:** Can you describe a time you containerized an AI model and deployed it via CI/CD?

### Ability to quickly prototype AI-driven products
> **[AI Guidance — Evaluator Aid]**
> - **Concept Summary:** AI prototyping involves rapidly building and testing models to validate ideas before full-scale implementation.
> - **Strong Candidate Signals:** Built 3+ AI prototypes with measurable outcomes in <2 weeks; Used MLOps tools like MLflow or Kubeflow for iterative testing
> - **Weak / Ambiguous Signals:** Conceptual understanding without hands-on prototyping; Prototypes that didn't connect to real user metrics
> - **Screening Question:** Give an example of an AI prototype you built with clear business impact in <2 weeks.

### What We Look For
> **[AI Guidance — Evaluator Aid]**
> - **Concept Summary:** AI Native Engineers design systems from the ground up using AI/ML principles for real-world applications.
> - **Strong Candidate Signals:** Built production AI models with TensorFlow/PyTorch; Deployed ML pipelines using Kubernetes or serverless
> - **Weak / Ambiguous Signals:** Studied AI concepts in courses; Used AI tools without deployment
> - **Screening Question:** Describe a production AI system you built from scratch.

### Strong problem-solving mindset
> **[AI Guidance — Evaluator Aid]**
> - **Concept Summary:** Strong problem-solving involves breaking complex issues into actionable steps with measurable outcomes.
> - **Strong Candidate Signals:** Solved production bugs reducing latency by 30%+; Optimized code for scalability in high-traffic systems
> - **Weak / Ambiguous Signals:** Solved simple coding puzzles; Identified issues without metrics
> - **Screening Question:** Share a time you improved system performance through technical problem-solving.

### Ability to work in fast-paced startup environment
> **[AI Guidance — Evaluator Aid]**
> - **Concept Summary:** Startup environments demand rapid iteration, adaptability, and resourcefulness with limited infrastructure.
> - **Strong Candidate Signals:** Launched features in <2 weeks using CI/CD; Scaled systems from 1k to 100k users with minimal cost
> - **Weak / Ambiguous Signals:** Worked in agile teams without ownership; Managed projects with no clear metrics
> - **Screening Question:** How did you handle technical constraints when building a feature quickly?

### Passion for AI-first product building
> **[AI Guidance — Evaluator Aid]**
> - **Concept Summary:** Building products where AI is the core driver from inception, not an afterthought.
> - **Strong Candidate Signals:** Built AI features with end-to-end ownership in production systems; Quantified impact of AI models on user engagement metrics
> - **Weak / Ambiguous Signals:** Mentioned AI without concrete examples or metrics
> - **Screening Question:** Can you describe an AI feature you built from scratch that directly impacted user retention?

### Ownership-driven and self-motivated attitude
> **[AI Guidance — Evaluator Aid]**
> - **Concept Summary:** Proactively driving work without external supervision, with clear outcomes.
> - **Strong Candidate Signals:** Delivered features ahead of schedule with measurable results; Owned cross-functional AI projects from ideation to deployment
> - **Weak / Ambiguous Signals:** Self-starter claims without specific deliverables or timelines
> - **Screening Question:** Tell me about a time you took initiative to solve a problem without being asked.
