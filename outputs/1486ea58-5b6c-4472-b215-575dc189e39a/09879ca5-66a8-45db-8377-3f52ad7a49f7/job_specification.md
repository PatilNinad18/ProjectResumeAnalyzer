## 4. Evidence & Evaluation Rules

### Understanding of cloud platforms (AWS / Azure / GCP)
> **[AI Guidance — Evaluator Aid]**
> - **Concept Summary:** Cloud platforms provide scalable infrastructure for AI workloads through managed services and global network access.
> - **Strong Candidate Signals:** Deployed production microservices on AWS/Azure/GCP with CI/CD pipelines; Managed containerized AI models using cloud-native services like SageMaker or Azure ML
> - **Weak / Ambiguous Signals:** Mentioned cloud platforms without deployment examples; Basic cloud tutorials without production context
> - **Screening Question:** Have you deployed an AI model on AWS/Azure/GCP with measurable results?

### Knowledge of deployment, Docker, and basic DevOps practices
> **[AI Guidance — Evaluator Aid]**
> - **Concept Summary:** Docker enables consistent environment isolation for reproducible AI development and deployment workflows.
> - **Strong Candidate Signals:** Containerized AI models using Docker with version-controlled images; Integrated CI/CD pipelines for automated model deployment
> - **Weak / Ambiguous Signals:** Docker tutorials without production usage; Generic mentions of containerization without metrics
> - **Screening Question:** Can you share a Docker image used in production AI deployments?

### Ability to quickly prototype AI-driven products
> **[AI Guidance — Evaluator Aid]**
> - **Concept Summary:** Rapid AI prototyping involves building and testing models with minimal infrastructure overhead.
> - **Strong Candidate Signals:** Built production-ready AI prototypes within 2 weeks using MLOps tools; Iterated models with real user feedback in live environments
> - **Weak / Ambiguous Signals:** Conceptual prototypes without deployment; Academic projects without real-world testing
> - **Screening Question:** Describe a time you shipped an AI prototype with user impact within 2 weeks.

### What We Look For
> **[AI Guidance — Evaluator Aid]**
> - **Concept Summary:** AI Native Engineers build systems that directly integrate AI models into production workflows without manual intervention.
> - **Strong Candidate Signals:** Deployed AI models via TensorFlow Serving or TorchServe in production; Integrated real-time AI pipelines with business logic using PyTorch or TensorFlow
> - **Weak / Ambiguous Signals:** Mentioned AI tools without deployment context; Tutorial projects with no production metrics
> - **Screening Question:** Have you deployed an AI model that handles real user requests at scale?

### Strong problem-solving mindset
> **[AI Guidance — Evaluator Aid]**
> - **Concept Summary:** Strong problem-solving mindset means identifying root causes and designing scalable solutions for complex technical challenges.
> - **Strong Candidate Signals:** Reduced latency by 40%+ through algorithmic optimization; Solved production incidents with zero downtime within 1 hour
> - **Weak / Ambiguous Signals:** Generic statements like 'good at solving problems'; Theoretical problem-solving without implementation
> - **Screening Question:** Describe a time you fixed a critical production issue with no downtime.

### Ability to work in fast-paced startup environment
> **[AI Guidance — Evaluator Aid]**
> - **Concept Summary:** Startup environments demand rapid iteration, cross-functional collaboration, and resourcefulness with limited infrastructure.
> - **Strong Candidate Signals:** Built features from concept to production in <2 weeks; Managed 10+ concurrent engineering tasks without blockers
> - **Weak / Ambiguous Signals:** Passive mentions of 'startup experience'; Idealized startup scenarios without real ownership
> - **Screening Question:** How did you adapt your workflow when resources were constrained?

### Passion for AI-first product building
> **[AI Guidance — Evaluator Aid]**
> - **Concept Summary:** Building products where AI is the core driver, not an afterthought.
> - **Strong Candidate Signals:** Led AI feature rollouts with measurable business impact; Published AI system designs in production environments
> - **Weak / Ambiguous Signals:** Mentioned AI in project descriptions without ownership; Used generic terms like 'AI-powered' without specifics
> - **Screening Question:** Describe an AI feature you built from concept to production with clear metrics.

### Ownership-driven and self-motivated attitude
> **[AI Guidance — Evaluator Aid]**
> - **Concept Summary:** Proactively driving work without external supervision through defined goals.
> - **Strong Candidate Signals:** Delivered features ahead of deadlines with self-defined metrics; Owned end-to-end product improvements with measurable outcomes
> - **Weak / Ambiguous Signals:** Volunteered for tasks without ownership; Referred to 'working independently' without concrete examples
> - **Screening Question:** Give an example where you took initiative to solve a problem without being asked.
